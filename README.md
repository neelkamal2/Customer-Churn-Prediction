# Customer Churn Prediction Using Machine Learning

## Project Overview
This project predicts whether a telecom customer is likely to leave the company (Churn) using Machine Learning algorithms.

## Dataset
The project uses the Telco Customer Churn dataset.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Spyder IDE

## Machine Learning Algorithms
1. Logistic Regression
2. Decision Tree
3. Random Forest
4. K-Nearest Neighbors (KNN)
5. Support Vector Machine (SVM)

## Project Steps
- Data preprocessing
- Handling missing values
- Encoding categorical variables
- Feature scaling
- Training and testing models
- Model evaluation and comparison

## How to Run
1. Install the required libraries using:

   `pip install -r requirements.txt`

2. Open the Python file in Spyder.
3. Make sure the CSV dataset is in the same folder as the Python file.
4. Run the program.
